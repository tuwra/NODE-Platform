# نـــود | NODE — Complete Runnable Website

A complete React/Vite website for NODE, following the supplied visual identity.

## Included
- Arabic + English with RTL/LTR switching
- Home, About, Workshops, Workshop details, Projects, Project details
- Events, Knowledge Hub, Community, Team, Achievements, Labs, Contact
- Admin login + dashboard
- Local demo content management
- Workshop registration demo with seat status
- Responsive mobile navigation
- SEO metadata
- Accessible labels and states
- NODE brand colors and fonts

## Run
Requirements: Node.js 18+ (Node 20+ recommended).

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Important production note
This version is a fully runnable front-end application with localStorage-backed demo authentication/content/registration. For a real public launch, replace the demo storage with a production backend such as Supabase/PostgreSQL, implement server-side authentication and authorization, real file storage, transactional seat locking, email verification/reset, rate limiting, audit logs, and server-side validation.
